# Release v9.3.5

First public test build of StreakWatch.

## Highlights
- Twitch LIVE/OFFLINE monitoring.
- Mozilla-signed Firefox Browser Bridge support.
- Managed LIVE-tab opening, deduplication and tab-level mute.
- Playback reporting and recovery.
- Network recovery and Bridge health monitoring.
- Discord webhook routing.
- Restart button and Desktop shortcut.
- Diagnostics, Safety timer, event/log history.

## Test-release warning
This is an early public test build. Twitch status detection relies partly on undocumented Twitch web interfaces and can require maintenance if Twitch changes them.

StreakWatch does not fake views, manipulate rewards, or guarantee Twitch Watch Streak credit.
